About the heavy truck warning: HUD's official DNL formula includes a specific adjustment factor for heavy trucks (from a reference called "Table 8") that isn't published in the documents this calculator was built from. The code currently assumes a default value for that one factor. In the one real test case checked so far, the heavy truck result matched HUD's own calculator almost exactly -- but that's only one data point, not a guarantee it holds for every speed/distance combination. See js/dnl-calc.js for details, and treat heavy-truck-heavy results with a bit of extra caution until confirmed further.

Data sources used by this tool

  • DNL formula: HUD Day/Night Noise Level Calculator
  • Texas AADT: TxDOT Annual AADT (Public View)
  • Texas speed limits: TxDOT Speed Limits (updated monthly)
  • Railroad crossings: FRA National Highway-Rail Crossing Inventory
  • Parcel boundaries: Regrid Nationwide Parcel Boundaries

Oklahoma, Tennessee, and Arkansas AADT sources are not yet configured -- see js/aadt-lookup.js.
