Update on the heavy truck factor: HUD's Table 8 (the heavy truck stop-and-go adjustment) has now been confirmed directly from the source document, "The Noise Guidebook" (p.57), and is fully implemented -- it's no longer a placeholder. Data sources used by this tool

This tool queries these sources live, every time you click a button -- nothing is stored or cached in the code itself. Whenever the source below publishes new data, this tool automatically reflects it on your very next click, with no updates needed here.

  • DNL formula: HUD Day/Night Noise Level Calculator
  • Texas AADT: TxDOT Annual AADT (Public View) -- published annually; current version's underlying data was last refreshed January 6, 2025
  • Texas speed limits: TxDOT Speed Limits -- extracted monthly from TxDOT's live asset system; every record includes its own extraction date (shown when you click a road on the map)
  • Tennessee AADT: TDOT Traffic Lines -- confirmed via live query (Aug 2026) at AADT year 2024, consistently across sampled records; includes a direct link to TDOT's own official record for each location
  • Tennessee speed limits: TDOT Road Geometrics -- no per-segment date field, but the dataset itself was last refreshed April 23, 2026
  • Railroad crossings: FRA National Highway-Rail Crossing Inventory -- continuously updated (not a periodic snapshot); last confirmed update May 12, 2026
  • Parcel boundaries: Regrid Nationwide Parcel Boundaries -- individual counties refresh roughly every 2 weeks on a rolling basis, with a full nationwide re-export every quarter
  • Street names on the map: looked up live from OpenStreetMap when you click a point, for any state whose own dataset doesn't include a street name field
